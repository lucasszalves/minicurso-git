# Minicurso de Git PET Informática
Neste minicurso, apresento aos alunos os conceitos básicos do uso do git e do GitHub no dia a dia de desenvolvimento de software. 

O minicurso foi realizado no dia 12/06/2026, na UFSC, por mim, Lucas Alves de Souza, graduando em Ciências da Computação.

Para elaboração do minicurso me baseei em muitos aspectos do curso [Learngit.io](https://app.learngit.io/education/). O link anexado redireciona ao site de inscrição para acesso gratuito e vitalício a estudantes, basta cadastrar com o e-mail institucional da sua universidade.
